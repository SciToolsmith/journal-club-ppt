# 按内容组织页面

规划版式和首轮制作时阅读。目标是每页信息分布充实、层次清楚、图文比例合适；正常边距和用于分组的留白必须保留。

## 先决定页面的视觉主体

每页先判断读者主要看什么、按什么顺序读，再选组件。不要仅按“有一张图/有三段话”分配固定坐标。

| 内容形态 | 优先组织方式 | 容易失败的套法 |
|---|---|---|
| 少量背景、动机或解释 | 带语义小标题的说明行；有真实关系时用原生示意/对照；也可配相关原图 | 三句短文顶在正文区上缘，结论条独占底部 |
| 单张证据图 | 主图占主要空间，图注紧随图，解释与图的视觉中心协调 | 将宽图塞入高图框，图和图注隔着大空白 |
| 两张证据图 | 按宽高比和对比任务决定并排、上下或主次布局 | 不论比例均强制五五开；三模态图缩到刻度难读 |
| 方法、公式 | 将输入、关键关系、更新和输出连成有方向的阅读路径 | 公式很小、四周空旷；用装饰箭头代替实际依赖 |
| 总结、讨论 | 用有主次的说明组整理贡献、证据边界和问题 | 将很短的结论拉成大行距或重复放进底部横带 |

栏目、配色、字体层级与页码沿用K105；正文布局可随内容调整。封面和结束页以模板横带形成整体视觉重心，不套正文的文字密度判断。`explanation` 是短说明的一种选择，不能让整套汇报都变成相同的说明行。

## 大空白的判断与修正

先观察**正文区**，排除页边距、栏目区和正常图表内部空间。若正文只占上半部、下半部大幅闲置，或文字与结论条之间出现横跨大半页的空白带，应判为需要重排。作为检查提示：连续空白带高约正文区的四分之一、宽约三分之二时，重点检查其是否有明确构图作用；该数值不是统一的“占满率”，不能靠增大空文本框绕过。

按具体问题修正：

1. **内容表达过于扁平**：从已有信息提炼语义小标题，将段落改成说明、对照或真实关系图。不要自动凑固定三个模块。
2. **图文比例失衡**：扩大核心证据、改变图文栏宽，或改为上下排列；图注跟随实际图像边界，不跟随一个空的大容器。
3. **内容组位置失衡**：整体调整垂直位置、限定段间距；不得把空白从中部简单挪到另一大块区域，也不能用夸张行距伪装充实。
4. **该页不足以独立成立**：在已确认总页数内与相邻页重分配内容，让另一张密集页释放关键证据；不增删最终总页数、不编造材料。

例如“周期冲击被噪声与干扰掩盖”的背景页，可以将原三段话组织为“识别对象—现有困难—本文思路”的说明关系，或用原生对象画出信号组成与分解目标。只是改写已有科学内容，不补入新结果。

## 逐页美观检查

先看整体，确认视线能自然经过标题、主体和结论；再看原尺寸，检查正文与图注的可读性。逐页检查：

- 主体的规模与信息重要性匹配，没有大空区、局部拥挤或一侧明显失重。
- 层次通过字号、字重、位置与间距形成，正文和图注有稳定的对齐关系；不靠堆卡片、边框和色块装饰。
- 图内坐标和图例能在汇报尺寸读清，数值与单位不拆开；视觉空间不足时换布局，不继续缩图缩字。
- 图注靠近所属图，解释和结论与证据保持联系；结论条是可选组件，不机械添加重复句子。
- 封面、正文、总结与结束页构成协调的整体，又允许按内容变化；美观不能以牺牲科学限定条件为代价。

构建器的 `layout_diagnostics` 只提示它能识别的稀疏文字、过浅图片等风险，并会加入代表页预览。程序未报警不代表美观，报警也不替代查看；依据实际页面修复后才能将 `layout_checked` 写为 true。
