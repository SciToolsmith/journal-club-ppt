# 按内容组织页面

只在选择不明确或实际版面出现问题时读本文件。先确定本页主结论、主次或顺序关系，再选合适的现有布局；条目数量不决定构图，避免同一内容尝试多套装饰方案。

| 内容 | 优先布局与关注点 |
|---|---|
| 独立短说明 | 简洁正文或 `explanation` 的 `prose`：标题在正文上方，按自然文字高度排列，保留合理留白 |
| 主论点与支撑 | `focus-left` 或 `focus-top`；第一组必须确为主论点，其余为支撑，依文案长度选择左右或上下安排 |
| 顺序、推理递进 | 原文支持明确顺序时用 `sequence` 的简洁箭头；不能把普通并列项画成流程或因果 |
| 对照、比较 | 按共同维度组织对照；必要时用表格或 custom，不为套布局虚构可比关系 |
| 一张图 | 主图占主要空间，图注紧随实际图像；宽图配浅图框，不强行五五图文分栏 |
| 两张图 | 按宽高比选择并排或上下；同一比较的图与解释靠近，不把核心图缩到不可读 |
| 方法、公式 | 保留理解结果所需的输入、关键关系、步骤与输出；复杂公式优先清晰裁图 |
| 总结、讨论 | 区分核心结论、边界与有依据的启发，按实际关系选正文或主次构图；不重复各结果页的全部要点 |

沿用 K105 的标题、配色和页码。封面、章节过渡与结束页保留模板留白，不套正文密度标准。信息页保证完整题名和元信息可读，不能为了填满页面编造期刊指标。

同为三点文字的背景、贡献和总结页不必同构，也不要把重复横条统一换成重复三卡片。`focus` 的首项不能只因排列第一就放大；`sequence` 的箭头必须有真实关系。选定的构图应让观众看出重点与关系，不为制造变化任意切换方向、重排科学含义或增加容器。用户明确提出的版式反馈是视觉验收要求，文字放得下不等于通过。

## 主体占用与留白

正文应避免无意大面积空白，同时保留正常边距、组间空隙和主图周围的呼吸空间。发现大片连续空白时，检查主体是否过小、挤在一端、重心失衡或图文分离；短文字不能原样缩成一小块就算完成。结合正文区域的主体占用、视觉重心与层级判断，不设置固定填充率，也不要求每页占满。

调整时先适度放大核心结论或关键证据，让图注和解释靠近，再按文案长度安排主次、分栏或真实关系；必要时在确认总页数内重分配相邻页。保持原图比例，不用等高三行、超大行距、重复结论、凑字或无关装饰消除空白，也不把合理分栏机械变成三张卡片。

`layout_diagnostics` 是提醒查看的线索，可能对合理留白报警。实际检查主体占用、重心、层级和用户要求后再判断，不为消除警告反复修改，也不以“正常留白”为由忽略明显稀疏。难辨图、裁切或遮挡等实质问题仍按 [quality-check.md](quality-check.md) 修复。
