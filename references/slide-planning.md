# 汇报页规划

总页数已确认且论文分析完成后阅读本文件。使用已有证据记录；字段、来源关联、导航及结构例外均以 [data-contract.md](data-contract.md) 为准，不另造页面 schema。

## 1. 先安排汇报结构，再分配证据页

封面、目录、章节过渡、正文、总结与结束页都计入用户确认总页数；不靠隐藏页、附页或减少某篇覆盖规避。独立篇数按 primary 计算，supplement 和 duplicate 不增加篇数。

- **单篇**：固定封面 → 1.1 文献基本信息 → 后续汇报小节 → 固定结束页。不设目录，也不在封面与信息页之间重复加“第1篇”过渡页。
- **多篇**：固定封面 → 总目录 → 第1篇章节过渡页 → 1.1 文献基本信息及该篇后续小节 → 第2篇章节过渡页 → 2.1 文献基本信息及该篇后续小节 → …… → 可选的综合思考章节 → 固定结束页。

多篇默认逐篇讲清，再做跨篇比较，不因主题相近就自动交叉讲。论文顺序可按用户要求、研究发展关系或讨论需要调整；一旦确定，目录、过渡页、正文编号与综合部分共同采用这一顺序。每篇分配多少页取决于贡献、关键证据量和理解难度，不机械平均。总目录可包含末尾综合章节；该章节若存在，也有自己的过渡页。

先扣除以上结构页，再安排正文。页数紧张时合并相近功能、压缩重复背景与次要推导；不能用过渡页或信息页代替一篇的实质汇报。若剩余页数不足以清楚覆盖论文，应说明实际页数冲突并请求调整，不静默改变总页数、丢弃主文或把字号缩到不可读。

## 2. 小节采用汇报框架，页内标题呈现论文内容

新计划使用 `navigation.profile: "group-meeting"`。正文左上为自动生成的“篇号.小节号＋小节名”，顶部为本页具体主题。同一小节可连续多页，编号保持不变。单篇也从 **1.1** 开始；小节号不等于物理页码。

每篇以下六项作为默认功能，不等于必须六页或六种固定版式。通用名优先，确有学科差异时选择备选名；不要把全部备选名串到一个标题中。

| role | 默认小节名 | 按论文类型选用的备选名 |
|---|---|---|
| `paper_info` | 文献基本信息 | 必须保留这个名称，并作为每篇第一个独立小节与正文页 |
| `background` | 研究背景与核心问题 | 问题提出与研究意义；学术背景与研究争议 |
| `methods` | 研究思路与方法 | 实验设计与方法；模型构建与求解；理论框架与分析路径；材料来源与研究方法 |
| `findings` | 主要结果与分析 | 研究发现与解释；理论结果与证明；核心观点与论证；案例分析与发现 |
| `appraisal` | 研究贡献与局限 | 创新点与不足；理论贡献与适用边界；论证评价与争议 |
| `implications` | 总结与研究启发 | 主要结论与启示；阅读思考与课题关联 |

备选分为**同一功能换名**与**内容需要时单独扩展**。可选扩展包括理论基础与研究假设（`theory`）、数据/材料与研究对象（`materials`）、关键机制/推导/证明（`mechanism`）、可靠性与适用性检验（`validation`）、文献比较与学术争议（`comparison`）。机器可读目录见 [report-sections.json](../assets/report-sections.json)。确有未覆盖的学术功能可用 `custom` 并说明理由；不能以此恢复逐条照抄原文目录。

可以将贡献、局限和启发合成“总结与讨论”，用一个 role 和 `covers` 记录兼顾的功能；也可以把方法或结果展开多页，必要时增加扩展小节。合并后按实际顺序连续编号，不留下 1.3→1.5 的跳号。文献基本信息不可与其他功能合并而消失。核心问题、理解结论所需的方法、主要发现和评价不能因未单设小节而遗漏；适用性较低的功能不凑内容。

“研究贡献与局限”评价论文的证据与论证，“总结与研究启发”回答如何理解其结论、哪些思路可借鉴。没有用户课题信息时，只写有原文依据的可借鉴方向或讨论问题，不编造“对本课题的应用”、个人进展和后续承诺。多篇末尾的综合部分突出各篇关系、差异和共同启发，避免重抄每篇结论。

### 文献基本信息页

每个 primary 都使用独立 `paper-info` 页。完整题名（原文题名，中文译名可另列）、作者、期刊/会议或其他发表载体、发表年份/日期和 DOI 等据原文填写；另给简短的主要研究内容与关键词。说明本篇研究什么、为何进入这次汇报即可，不在这里展开结果论证。长作者列表上屏可用第一作者等，完整作者保留备注；原文未提供的信息省略，不填占位符。

IF、分区不是跨学科必填项，也不能沿用模板示例值。仅用户要求且有可靠的对应年份/体系来源时加入；没有这些指标并不代表信息页不完整。论文题名与出处从总封面移到本页，不重复制作论文式总封面。

### 目录与章节过渡

目录以每篇短题名加序号呈现，完整题名放信息页；不把所有 n.1—n.6 塞进总目录。多篇目录目标指向各自章节过渡页，起始页码由最终计划计算。过渡页沿用 K105 的细边框、顶部大号章节号和列表：当前篇使用主题色及深色文字，其余篇弱化，条目与目录保持相同顺序；可包含综合章节。页数超过模板示例的三篇时按真实篇数调整，条目过多时采用分组或分栏的可读变体，不能悄悄漏项。

页内具体主题可写“CK 目标与滤波器更新”“关键对照中的结果差异”等；它们属于对应的通用汇报小节，不能直接变成整套导航的小节目录。标题中的判断仍须有依据，不用“效果更好”等空泛或过强结论。封面、目录、章节过渡和结束页不套正文双层标题。

## 3. 为每页确定任务、证据和版式

内容页通常只推进一个主要信息：它回答什么问题、凭什么证据、在什么条件下成立。选择足够的文字、图表和必要方法条件，按数据契约关联来源；多个证据仅在共同回答这一信息时同页呈现。作者陈述、阅读分析与假设应在文案中分清。

按图表形状、数量和解释需求选择版式，明确必须保留的图内要素。PPTX 页内使用简短来源标识与必要定位，不依赖额外交付文件追溯；参考文献页若使用也计入总页数。复用实验条件时使用已有命名引用，避免在正文、图注与比较表中重复手填。

选择版式时按 [layout-composition.md](layout-composition.md) 判断视觉主体、阅读顺序和内容分布。少量短文不直接套整宽置顶段落；宽图、竖图和密集多模态图不默认使用相同图框。若一页明显稀疏而相邻页拥挤，先在固定总页数内调整证据分配。

保留核心问题、理解结果必需的方法、决定结论的证据和边界。按汇报目的安排方法深度，应用/概览不强制完整推导；方法图须表达真实依赖与回环。复杂公式可用原文高清裁图配可编辑符号解释，保持编号、必要定义和条件；用户要求全元素可编辑时再重建。无需为每项负结果或每条局限单设页面。

## 4. 让图证据和总结各司其职

图表承载主要证据时占主要空间。围绕本页结论给简短读图提示：看哪个面板、比较什么组、关注何种趋势或差异；结合必要条件说明关键发现，不逐项复述数值。提示用独立可编辑文字或标注，不能遮住原图或改变证据。

不靠持续缩小字号、挤图或删除图例满足页数。优先减少同页对象、拆出相关子图、合并重复叙述或重分配其他页；调整后同步计划、导航与精确总页数。原生流程和重建表格的关系、数值也须可追溯。

总结先回答开头的研究问题，再提炼得到支持的贡献与适用边界，最后提出有依据的讨论问题。明确主次，不把各结果页要点再次堆成等权列表，也不让固定结束页替代总结。内部分析可详尽，上屏内容服务汇报，不把分析表整表粘贴或逐项变成页面。

## 5. 进入制作前

核对计划页数与默认结构/已记录例外、主线连贯性、各主文实质覆盖、结论与图表来源、比较条件及版式可读性；删除重复页面、无依据的新颖性判断和凑数建议。若需猜数据或重造证据才能成立，应重写该页。

制作中先预览实际版式变体和难页，按 [quality-check.md](quality-check.md) 复核；需要调整时回到相应证据或页面计划，修复后检查受影响页面与全稿页数。最终 PPTX 仍须完整渲染并逐页查看，内部计划、分析和预览不作为额外附件交付。
