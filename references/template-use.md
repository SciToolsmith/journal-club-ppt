# 使用 K105 模板组件

制作时读取 `assets/k105-blue/starter-manifest.json`，必要时在任务目录渲染 `starter.pptx` 对应页。公开包包含干净 starter 与原生组件，不包含原始参考 PPT 或其截图；普通任务不依赖这些原件，也不需要逐次重新生成模板。

版式沿用 K105，主题由任务记录读取，配色以 `assets/theme-palettes.json` 为准：

| 主题 | theme_id | 主色 |
|---|---|---|
| 蓝色 | blue | `#32497B` |
| 青色 | teal | `#2F6B76` |
| 红色 | red | `#AD2C34` |
| 紫色 | purple | `#671D6F` |

青、红、紫只采用新增模板的实测配色，不引入其版式或毕业答辩内容。新任务须已有用户颜色回答；蓝色 starter 不构成默认选择。封面、标题、角标、目录、表格、流程和结束页统一换色，科研原图像素与颜色不变。

- 页面为 1280×720，白底、左上栏目导航、细分隔线、右下页码，正文顶部保留具体主题；导航组织见 [slide-planning.md](slide-planning.md)。封面保留原生横带和角落短线。
- 封面横带上方不放任何眉题或汇报类型标签，不用文字或装饰补满该模板留白。题名和研究主题位于横带内，必要论文信息位于横带下方；此要求也适用于自定义封面和复用旧版模板。
- 组件是对原版的可读性适配，不保证对象结构完全相同。图表按比例放置，保留必要标记与图例；密集图拆页或选相关子图，不以缩字号硬塞。首轮版式变体与成品检查见 [quality-check.md](quality-check.md)。
- 检查当前环境字体并显式传入，优先模板字体；缺字时改用已安装中文字体，记录替代家族并实际渲染验证，不写入其他机器的路径。
- 题名、作者、期刊、日期、数值来自用户论文，缺失则省略，不保留模板示例或 XXX。
- 固定结束页复用原模板第 25 页：白底、主题色横带、居中白字“汇报完毕，敬请老师同学批评指正！”，保留角落装饰；删除英文说明及空的汇报人/日期占位。保持原生可编辑，不加正文标题栏、来源或讨论。结构例外见数据契约。
- 多篇目录延续原模板第 2 页的视觉层级，用实际短题名/主题与自动起始页码，单篇默认无目录。
- 特殊布局用 `derived:` 并注明理由，延续主色、标题与留白，保持来源和原生可编辑性；字段要求见 [data-contract.md](data-contract.md)。

维护组件时再看 [template-maintenance.md](template-maintenance.md)。`layout-catalog.json` 是公开的语义版式索引，保留计划使用的 ID 与用途，不是原模板对象清单或精确填充 API。
