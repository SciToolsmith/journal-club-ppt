# 使用 K105 模板组件

制作时读取 `assets/k105-blue/starter-manifest.json`，只看本次采用版式的预览，必要时渲染 `starter.pptx` 对应页。常规任务用干净 starter 与组件；`reference.pptx` 是不可修改的用户外观依据，不每次重新导入、清理并渲染全部 25 页。

版式沿用 K105，主题由任务记录读取，配色以 `assets/theme-palettes.json` 为准：

| 主题 | theme_id | 主色 |
|---|---|---|
| 蓝色 | blue | `#32497B` |
| 青色 | teal | `#2F6B76` |
| 红色 | red | `#AD2C34` |
| 紫色 | purple | `#671D6F` |

青、红、紫只采用新增模板的实测配色，不引入其版式或毕业答辩内容。新任务须已有用户颜色回答；蓝色 starter 不构成默认选择。封面、标题、角标、目录、表格、流程和结束页统一换色，科研原图像素与颜色不变。

- 页面为 1280×720，白底、左上栏目导航、细分隔线、右下页码，正文顶部保留具体主题；导航组织见 [slide-planning.md](slide-planning.md)。封面保留原生横带和角落短线。
- 新汇报固定封面复用原第 1 页：白底、主题色横带、角落短线，横带中央大字“组会汇报”；带下保留原学士帽/日历图标，填写已确认的汇报人和生成当天日期。横带上方无文字，保留模板留白。论文题名、研究主题和引文放各篇信息页，不挤进总封面。
- 组件是对原版的可读性适配，不保证对象结构完全相同。图表按比例放置，保留必要标记与图例；密集图拆页或选相关子图，不以缩字号硬塞。首轮版式变体与成品检查见 [quality-check.md](quality-check.md)。
- 检查当前环境字体并显式传入，优先模板字体；缺字时改用已安装中文字体，记录替代家族并实际渲染验证，不写入其他机器的路径。
- 论文题名、作者、发表载体、发表日期和数值来自论文，缺失则省略；汇报人来自用户、汇报日期来自实际生成日，两种日期不混淆。不保留模板示例、XXX 或 20XX.XX.XX。用户明确不显示姓名时，封面/结束页同时省略姓名行及相应图标，日期保留。
- 固定结束页复用原第 25 页：白底、主题色横带、居中白字“汇报完毕，敬请老师同学批评指正！”，保留角落装饰；删除 `Group Literature Report PPT Template - Multiple Literature Version`，下方填写与封面一致的真实汇报人和生成日期。保持文字原生可编辑，不加正文标题栏、来源或讨论。
- 多篇目录延续原第 2 页的视觉层级，采用各篇短题名与自动起始页码。每篇进入前复用第 3/10/15 页章节过渡设计：细边框、顶部大号序号和完整章节列表，当前篇主题色高亮、其他篇弱化；可选综合章节沿用第 20 页。单篇无目录和章节过渡，封面后直接是“1.1 文献基本信息”。
- 文献信息页延续原第 4/11/16 页的身份信息、主要研究内容与关键词功能，使用真实元信息和可编辑文字。跨学科不强制 IF、分区或期刊封面，长原文题名必须完整可读；后续章节使用通用汇报小节，原论文自身标题作为页内主题。
- 特殊布局用 `derived:` 并注明理由，延续主色、标题与留白，保持来源和原生可编辑性；字段要求见 [data-contract.md](data-contract.md)。

仅直接复用原版或维护组件时，再看 [template-maintenance.md](template-maintenance.md) 与 `layout-catalog.json` 的页清单、对象提示和清理项；普通任务不加载整套维护材料。
