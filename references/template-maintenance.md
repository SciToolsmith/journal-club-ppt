# K105 蓝色模板使用

制作前读取 [版式目录](../assets/k105-blue/layout-catalog.json)，按需查看其中的预览。设计依据是 [reference.pptx](../assets/k105-blue/reference.pptx)。预览由使用中文替代字体的环境渲染，仅供外观参考；换行、英文截字和字宽不代表源文件的最终显示效果。模板许可状态为 `user-supplied-reference`，不据此声称可再分发。

## 选择与填充

- 以用户已回答的**总页数**分配封面、论文内容、综合比较和结束页。总页数包含所有页；篇数和每篇页数不受原模板“三篇、25页”的示例限制。
- 从对应源页复制到独立的工作演示文稿，再填充文字、表格、图表和图片；不修改参考文件。按当前制作工具保留版式与关联资源，先核验复制后的对象结构。
- `layout_id` 是本技能的版式分类名。目录中的源页号只是参考文件里的页序，`source_shape_id` 也只在对应源页局部有效。导入、复制、重排或导出后须重新读取对象树，结合文字与位置识别目标。目录提供对象提示，**没有实现精确填充 API 或稳定语义槽位**。
- 源文件正文主要由原生形状和文本框组成，未建立标题/正文占位框。不要假设“新建幻灯片”会自动生成目录里的复杂版式。
- `paper-info` 的源P4、P11、P16各含一个原生5×2表格。`results-table-chart` 的源P7含原生7×5表格与原生折线图，图表关联嵌入Excel工作簿。更新真实数值时保持工作簿、图表数据及显示一致，导出后验证关联仍有效。
- 其他科研图多为整体图片，图片里的表格和坐标轴不能直接编辑。源P19左下表格也是位图。保持标题、结论和图注可编辑；需要可编辑数据图表时，只能依据论文给出的可靠数值重建，不从曲线外观猜测数据。

## 每次复用均需清理

- 清除封面/结束页中的 `XXX`、`20XX.XX.XX`，所有“请输入”文案，以及模板结束页的 `Group Literature Report PPT Template - Multiple Literature Version`。如保留英文目录与章节提示，使用完整且匹配的 `CONTENTS`、`PART ONE` 等，不照抄预览中的截字。
- 替换目录和全部章节过渡页中的三篇示例题名：`Cold and hot tumors…`、`Cancer cells impair monocyte…`、`PD-1-PD-L1 immune-checkpoint…`。原论文截图、期刊封面、实验图和图注同样必须替换。
- 清除三个文献信息表中重复的 `Nature`、作者“星淇”、`SCI一区`、`60.61` 与日期占位。用上传论文的真实题名、作者、期刊、年份和DOI填充；无可靠依据时删除IF或分区字段，不保留演示值。
- 源P7的表格数字、系列1–3、数据1–4都是演示数据，不能带入结果。源P8/P9复用了同一张图片，不能当作两项独立实验。
- 源P21中央装饰椭圆中含孤立文本 `90`，可能被其他对象覆盖。检查对象文本并清除这类残留，避免只凭预览判断清理完成。

清理只针对模板残留，不删除用户论文真实出现的同名期刊、术语或数值；通过来源映射确认应保留的内容。

## 目录、编号与可读性

- 依据最终论文顺序统一目录、章节高亮、章节编号、页标题、页码和图表编号。删除或增添页后重新联动检查，不沿用源页脚数字。目录项优先短题名，完整题名保留在文献信息页。
- 先按比例适配科研图，避免非等比拉伸。只裁去无关空白；必须保留所选面板的标记、坐标轴、图例、单位和解释所需信息。复杂图优先减少同页图数或拆页，不通过缩小到不可读来满足版式。
- 原模板主题主色为 `#32497B`，白底、灰色辅助色、左上页标题及细分隔线构成正文风格。字号和字体实测记录见目录；原版若干正文仅12–14pt，属于容量风险。先精简内容和减少列数，再检查字号，避免继续缩小。
- 源文件使用微软雅黑主题，局部有思源黑体、Roboto及阿里巴巴普惠体。制作时检查字体可用性；替代字体后逐页渲染检查文本溢出、英文截字和图注清晰度。预览不能代替最终演示文稿的视觉检查。

## 跨文献综合

源模板的P21–24提供总结与反思布局，没有真正的跨文献比较矩阵。需要比较多篇论文时可新增原生表格，沿用主色、留白、页标题和细分隔线，比较研究问题、方法、关键证据和结论边界。明确这是适配版式，不声称来自某个原模板页。

总结、阅读启示或方法借鉴应基于上传论文；不要填成用户个人实验进展、已完成工作或未经提供的后续安排。模板资产、预览和内部检查材料留在工作区，最终交付遵循主技能约定，仅一个可编辑PPTX。
