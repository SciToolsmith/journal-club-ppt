# 论文分析与证据整理

在 [SKILL.md](../SKILL.md) 的总页数确认关卡通过后阅读本文件。记录字段、来源角色和引用规则以 [data-contract.md](data-contract.md) 为唯一权威；本文件只指导科学判断。

## 1. 通读并建立证据清单

沿用 init 分配的文件来源编号，识别主文、补充和字节相同的重复文件；不同主文修订版保留独立来源并说明关系。对每篇主文通读摘要、引言、方法、结果、讨论及图表说明，理解研究问题、作者主张、设计和结论边界。补充材料按关键证据需要阅读；重复文件可核对字节一致后沿用主文审阅，记录实际阅读范围。

建立全部正文主图主表清单，逐张查看实际内容与图注，辨明各子图作用后才填写审阅状态；没有主图表也须显式记录空清单。先复用全文和可读页面预览；关键图、难辨图及可能改变结论的图须放大。预处理或读摘要、图注不能替代实际审阅；展示所需的独立高清素材在选图后生成，审阅中的放大按需进行。

内部记录保留足以核验和规划的信息：

- 可靠的原文定位、研究对象、比较条件、测量指标与实际结果；未知页码、数值或条件不补造。记录不可读页、缺失材料与版本冲突。
- 关键证据的支持范围、不能推出的结论及必要的不确定性、样本量、误差线和统计检验；原文未报告则如实说明。次要证据只留必要记录，不复制正文。
- 区分原文观察、作者解释、AI 分析和待检验推测。AI 的质疑不能写成作者承认的局限；未经独立核验，相关工作只作为作者概括，不替作者确认完整发展史、“首次”或“最佳”。

重复实验条件集中记录并供页面引用，避免多处手抄。同一图支持不同结论时注明各自子图和边界；一个结论依赖多项证据时保留全部关联。记录粒度及裁图引用方式见数据契约。

## 2. 按研究类型检查科学逻辑

为每篇选择主要分析类型；仅当另一项独立贡献可能漏检时增加次类型。类型决定检查重点，不强制章节、页数、公式或模块表。难以归类时沿用“问题—设计—证据—结论边界”。

| 类型 | 核查重点 |
|---|---|
| 方法、算法或系统 | 输入输出和关键步骤；隔离实验是否支持组件作用；消融是否只改变目标因素；基线、数据、预算与可用输入是否公平；完整系统与局部能力是否混淆。 |
| 发现或机制 | 观察、干预、对照、重复和替代解释；区分相关性、必要性、充分性与机制，不从表型或相关关系直接推导因果。 |
| 数据集、基准或资源 | 构建标注、纳入排除、划分、质量与覆盖；泄漏或污染；规模与有效性分开；指标是否测量所声称的能力。 |
| 临床或人群研究 | 人群、比较、结局、随访、缺失与混杂；预设与探索分析、绝对与相对效应；统计显著、实际效益与外推人群分开。 |
| 材料、化学或工程 | 制备、表征和工作条件；结构、性质、机制与性能间的证据；可比条件、指标归一化、批次、误差、耐久性与规模化边界。 |
| 综述、观点或荟萃分析 | 范围、选文和综合方法；异质性及偏倚；观点与证据综合分开；分类的覆盖、反例和遗漏，不强求模块消融。 |

只记录与主要主张有关且材料允许判断的问题。讨论来自具体证据、假设或矛盾，解释讨论价值；不按数量凑局限或研究想法。

### 方法解释

方法、算法或系统论文须按数据契约记录输入、目标、关键求解/更新、输出及停止条件的覆盖情况。解释各步骤为何连接；迭代流程核对更新对象、依赖顺序、回到哪一步、继续与终止分支，不能把迭代画成只向前的流程。若显示公式，核对符号定义、上下标、索引、运算符和条件，解释其在求解中的作用。

记录真实的未展示或不适用理由，不固定增加公式页；非迭代方法不强造停止规则。页数紧张时先压缩重复背景和次要结果，不能将核心求解压成一句“优化”。

## 3. 从已审阅证据中选图

全部审阅不等于全部上屏。围绕核心问题及确认页数选择证据，保留会改变结论的对照、负结果或不确定性，不能只选有利结果。

优先使用原文图表。裁剪可去空白或分离子图，但保留必要的坐标、单位、组别、图例、比例尺、误差线、统计标识及首末刻度。按幻灯片实际尺寸检查；密集图优先拆子图、扩大图区或选取相关局部，必要说明用可编辑文字补充并核对原文。不以生成式重画、猜测数值或修改曲线提高可读性；无可靠数据时科研图保留为独立可替换图片。

## 4. 多篇综合与分析收尾

先逐篇整理证据，再判断共同问题、方法延续、证据互补或结论分歧；联系不足则分篇介绍。跨篇比较核对对象、任务、指标定义与方向、单位、条件、时间尺度和预算；条件不足时说明差异与限制，不无依据排序、合并效应或换算数值。

共同结论须由各篇分别支持，区分作者直接比较与 AI 整理。每篇独立主文均须得到与总页数相称的实质介绍；数据契约检查自身证据覆盖，但不能代替判断介绍是否充分。

规划前核对核心数字、术语、单位、组别、图号及结论强度；保留未展示但影响解释的证据。随后按 [slide-planning.md](slide-planning.md) 压缩为指定总页数，针对性独立复核与最终逐页检查见 [quality-check.md](quality-check.md)。
