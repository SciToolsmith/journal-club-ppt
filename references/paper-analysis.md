# 论文分析与证据整理

在 [SKILL.md](../SKILL.md) 的总页数确认关卡通过后阅读本文件。记录字段、来源角色和引用规则以 [data-contract.md](data-contract.md) 为唯一权威；本文件用于按研究类型查核或处理具体证据疑点，不是普通任务必须全文加载的第二份流程。

## 1. 全篇筛查，再围绕主线精读

沿用 init 分配的编号，识别主文、补充和字节相同的重复文件；不同修订版保留独立来源并说明关系。根据用户目的、论文贡献与页数安排深度，不新增必答问题。先通览各章节，阅读摘要、问题与结论，浏览全部主图主表的实际内容及图注，建立研究问题、方法、实验与边界的整体认识；不逐句深读所有背景、证明和次要实验。

建立完整主图主表清单，区分“已筛查”和“已核验”；无主图表则填空清单。筛查须看实际图内容和图注，足以判断作用与相关性，不能只读图号。准备展示、支撑结论或可能改变主要判断的证据须精读正文及必要前后文，核实图中结果、比较条件和边界；难辨关键图须放大。摘要与结果冲突、图注不足以判断、方法理解不连贯或对照条件存疑时扩读相关部分。初筛看清图的研究主题、比较对象和作用即可；不入选且不改变主要解释的图无需逐坐标抄数值。不能判定是否重要时再放大或扩读。

补充材料按关键证据需要阅读；同字节重复文件可沿用核验，记录实际范围。高清素材在选图后提取。预处理不代表完成筛查或核验；具体状态字段见数据契约。

内部记录保留足以核验和规划的信息：

- 展示或支撑结论的内容保留可靠定位、研究对象、比较条件、指标和实际结果；核对其中数字、单位与参数，以及未上屏但会改变结论的条件，不逐项核算无关实验。未知信息不补造，影响汇报的不可读材料或版本冲突须处理。
- 关键证据的支持范围、不能推出的结论及必要的不确定性、样本量、误差线和统计检验；原文未报告则如实说明。次要证据只留必要记录，不复制正文。
- 区分原文观察、作者解释、AI 分析和待检验推测。AI 的质疑不能写成作者承认的局限；未经独立核验，相关工作只作为作者概括，不替作者确认完整发展史、“首次”或“最佳”。

以 papers.json 为主记录，并行时可先写 P1/P2 记录再合并。除跨记录推导或疑点确有需要外，不另写同内容的长分析或逐图复述。次要图保留筛查记录，关键图保留核验结果，不能把两者混写。

重复实验条件集中记录并供页面引用，避免多处手抄。同一图支持不同结论时注明各自子图和边界；一个结论依赖多项证据时保留全部关联。记录粒度及裁图引用方式见数据契约。

## 2. 按研究类型检查科学逻辑

为每篇选择主要分析类型；仅当另一项独立贡献可能漏检时增加次类型。类型决定检查重点，不直接决定汇报小节名称；上屏章节采用 slide-planning 的通用功能及学科备选名。难以归类时沿用“问题—路径—证据或论证—结论边界”。

| 类型 | 核查重点 |
|---|---|
| 方法、算法或系统 | 输入输出和关键步骤；隔离实验是否支持组件作用；消融是否只改变目标因素；基线、数据、预算与可用输入是否公平；完整系统与局部能力是否混淆。 |
| 发现或机制 | 观察、干预、对照、重复和替代解释；区分相关性、必要性、充分性与机制，不从表型或相关关系直接推导因果。 |
| 数据集、基准或资源 | 构建标注、纳入排除、划分、质量与覆盖；泄漏或污染；规模与有效性分开；指标是否测量所声称的能力。 |
| 临床或人群研究 | 人群、比较、结局、随访、缺失与混杂；预设与探索分析、绝对与相对效应；统计显著、实际效益与外推人群分开。 |
| 材料、化学或工程 | 制备、表征和工作条件；结构、性质、机制与性能间的证据；可比条件、指标归一化、批次、误差、耐久性与规模化边界。 |
| 综述、观点或荟萃分析 | 范围、选文和综合方法；异质性及偏倚；观点与证据综合分开；分类的覆盖、反例和遗漏，不强求模块消融。 |
| 数学或理论研究 | 定义、前提、定理结论、证明思路及适用条件；区分已证明结论、猜想和数值示例，不编造实验验证。 |
| 人文、历史、哲学或文本研究 | 材料/文本/史料范围、概念界定、解释路径、关键论据、反例与不同解读；区分材料事实与作者阐释，不强造样本量、显著性或实验流程。 |
| 社会科学、质性或案例研究 | 研究对象选择、资料获取与分析路径、解释证据及研究者立场；区分案例内解释、跨案例归纳和可外推结论。 |

只记录与主要主张有关且材料允许判断的问题。讨论来自具体证据、假设或矛盾，解释讨论价值；不按数量凑局限或研究想法。

### 方法解释

方法深度服务汇报目的：方法精读保留关键更新与推导逻辑；应用或多篇概览可用输入、核心思想、必要步骤和输出来说明方法，不为每篇重现数学推导。普通组会省略 method_coverage 表，直接在页面内容和来源中交代必要方法；仅方法精读、复现需求或具体疑点需要时才使用该可选记录。停止条件只有影响理解时才展开。理解主要贡献必需的环节不能省成“进行优化”。

展示的迭代流程须准确表达更新对象、依赖顺序和回环，非迭代方法不强造停止规则。公式可用清晰原文裁图配可编辑说明，无须为可编辑性手工重建每个符号；无论采用何种形式，都核对必要符号、索引、运算关系及条件，不截掉会改变含义的定义。未展示的次要推导不逐项写省略理由，不固定增加公式页。

## 3. 从已审阅证据中选图

从筛查清单中选图，再完成入选证据核验。保留影响主要判断的对照、负结果或不确定性，不罗列所有失败实验或为凑“批判性”制造局限。未入选但会改变结论的证据同样核验，不能只选有利结果。

优先使用原文图表。裁剪可去空白或分离子图，但保留必要的坐标、单位、组别、图例、比例尺、误差线、统计标识及首末刻度。按幻灯片实际尺寸检查；密集图优先拆子图、扩大图区或选取相关局部，必要说明用可编辑文字补充并核对原文。不以生成式重画、猜测数值或修改曲线提高可读性；无可靠数据时科研图保留为独立可替换图片。

## 4. 多篇综合与分析收尾

先逐篇整理证据并独立汇报，再在综合部分判断共同问题、方法延续、证据互补或结论分歧；联系不足就如实说明，不强行串成共同结论。跨篇比较核对对象、任务、指标定义与方向、单位、条件、时间尺度和预算；条件不足时说明差异与限制，不无依据排序、合并效应或换算数值。

共同结论须由各篇分别支持，区分作者直接比较与 AI 整理。每篇独立主文均须得到与总页数相称的实质介绍；数据契约检查自身证据覆盖，但不能代替判断介绍是否充分。

规划前核对核心数字、术语、单位、组别、图号及结论强度；保留未展示但影响解释的证据。随后按 [slide-planning.md](slide-planning.md) 压缩为指定总页数，针对性独立复核与最终逐页检查见 [quality-check.md](quality-check.md)。
